# Hack The Box – First Steps

My journey into cybersecurity and ethical hacking through **[Hack The Box](https://www.hackthebox.com/)**.

This repository contains my notes, methodology, commands and write-ups from the machines I solve.


##  Objectives

- Improve Linux and networking skills.
- Learn reconnaissance and enumeration techniques.
- Understand common vulnerabilities and exploitation methods.
- Practice privilege escalation.
- Document each step and the lessons learned.

## 🛠️ Methodology

For each machine, I generally follow these steps:

1. **Reconnaissance** – Identify open ports and running services.
2. **Enumeration** – Investigate services, directories and potential attack surfaces.
3. **Exploitation** – Identify and validate vulnerabilities.
4. **Privilege Escalation** – Explore ways to obtain higher privileges.
5. **Documentation** – Record commands, findings and lessons learned.

##  Disclaimer

All activities documented here are performed in authorized lab environments for educational purposes.

**The goal is to learn, understand and improve — one machine at a time.**
